# Demo prompts

## The one prompt, used twice

Used before the Skill exists and again after, word for word.
That repetition is the entire demo.

```
Create a report about my last week.
```

## Other phrasings the Skill should also catch

Use these if you want to show the Skill activates on variations,
not just the exact string above.

```
Create my weekly Garmin report.
```

```
How did I perform last week?
```

```
Give me my training and recovery summary.
```

```
Generate my weekly health and training report.
```

## Notes for the presenter

- Don't reword the main prompt between runs. If you improve the
  prompt, you're not testing the Skill anymore, you're testing a
  better prompt.
- If the agent asks a clarifying question in the "without skill"
  run, answer minimally and vaguely -- that's realistic. Don't feed
  it the answer key.
- Keep the without-skill transcript. You'll want to read a line or
  two out loud during the comparison.
