## Ground rules for this table

- No invented numbers. If you didn't measure it this run, it's a
  `?`, not a guess.
- "Repeatability" means: if you run it again tomorrow, does the
  shape of the report stay the same? You can only answer this
  once you've actually run it more than once.
- Token usage can be shown here too, for fun, if you happened to
  capture it. It is not the point of this table and nobody should
  walk away thinking Skills exist to save tokens.

## What this table is actually demonstrating

Not "the Skill is smarter." The model didn't change.

What changed is that the team's judgment calls -- which period,
which metrics, what counts as notable, what language is safe --
got written down once, in a place the agent reads before doing
the job.
